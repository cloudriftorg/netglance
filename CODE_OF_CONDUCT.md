# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its code of
conduct. The full text is available at:

➡ <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be respectful, be constructive, assume good faith. Treat the
project's communication channels (issues, discussions, PRs, any chat
rooms) with the same standards.

## Reporting

Conduct concerns can be reported privately to the project maintainer.
The current maintainer email is in the `MAINTAINER=` field of the
project's `Makefile` and in the latest commit's author metadata.

Reports are read by the maintainer only. We aim to acknowledge within
~5 working days and to act in proportion to the severity of the
incident, up to and including a permanent ban from project spaces.
